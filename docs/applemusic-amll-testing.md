# Apple Music 播放器使用与手动检查

## 安装

1. 在项目目录运行 `npm ci`（首次安装依赖），随后运行 `npm run package:chrome`。
2. 暂时关闭商店版或其他版本的 YouLy+，在 Chrome / Edge 扩展页开启开发者模式，加载 `dist/youlyplus-amll-chrome`。
3. 刷新 [Apple Music 网页](https://music.apple.com/)，播放歌曲并打开展开/全屏歌词播放页。

每次更新后重新打包、重载扩展并刷新网页。`npm run dev` 只提供模拟预览，不播放真实音频。本项目现在仅支持 Apple Music；旧 YouTube Music、Tidal、字幕和 SponsorBlock 链路已经移除。

## 播放器和设置

播放器保留本地 AMLL 的 PrebuiltLyricPlayer、布局、图标、逐字遮罩、弹簧及背景动画，并在扩展自己的 iframe 文档中渲染。父 Apple 页面只转发歌曲、播放时间和控制命令，不向 frame 传递 LLM 密钥或 MusicKit 凭据。启动失败自动退回原生，菜单也可主动切回。

菜单内提供歌词显示模式、来源、偏移、动态背景、本地 TTML 和原生下载。菜单与播放队列互斥，打开和关闭使用统一的淡入淡出、轻微缩放及位移动画，并遵循系统的减少动态效果偏好。显示模式与来源采用与播放器一致的圆角选单，支持方向键、Home/End 和回车选择；Esc 依次关闭选单、面板，再退出播放器。队列打开时随切歌/队列变化刷新。浏览器全屏入口兼容横竖布局；AirPlay 由浏览器能力决定。

扩展设置和弹窗仅保留 Apple Music 有效项。支持逐字开关、轻量模式、原文/音译主副轴、全播放器字体与字体文件导入、歌名修正（关闭/原地区/中国大陆/日本）、歌词来源、翻译/音译及存储管理。字体文件支持 TTF/OTF/WOFF/WOFF2，最大 64 MB，保存在扩展 IndexedDB；恢复默认会清理当前导入字体。

设置自动保存，翻译服务、模型、提示词、目标语言变更会重新应用到当前歌曲，旧请求结果不会覆盖新配置。翻译/音译缓存按有效配置和歌词版本区分。原生目标语言变化会在页面内重新请求，无需单独刷新网页。总开关需要重新加载页面时按设置提示操作。

## 歌词来源与本地 TTML

在线来源按 **AMLL TTML DB → LunaBeat → AmLyrics → Apple Music 原生** 获取，前三个可排序/移除/添加，Apple 原生固定最后回退。自动模式优先使用已导入的本地歌词。手动来源与偏移按 Apple ID 保存，选择“自动”恢复自动顺序；手动来源暂不可用时允许回退，保留偏好。

播放器菜单的“导入 TTML”将文件绑定当前歌曲的 Apple ID；支持 `.ttml` / TTML 内容的 `.xml`，最大 2 MB。再次导入替换当前歌曲本地版本；无效文件不会替换已有文件，选择期间切歌会取消。主唱、和声、对唱、时间轴和自带翻译/音译经同一 AMLL 解析。设置页仅管理本地库及删除，不再提供按歌名匹配的另一套上传。旧版按元数据保存的文件继续兼容，匹配当前歌曲后迁移到 Apple ID；建议有同名多版本时从当前播放器重新导入。

“移除导入的 TTML”删除本地版本并恢复自动来源。设置页删除也会通知当前页面刷新。本地歌词、字体、按歌曲保存的来源/偏移不属于可随意丢弃的在线缓存。

“下载 AM 原生 TTML”保存当前歌曲的原始文件，含歌手、歌名和 ID；即使当前显示第三方源也能下载，不切换来源。文件保留 AM 返回的时间及自带翻译，不加入机翻或显示阶段的繁简转换。切歌会取消下载；无原生文件时明确提示。

离线提取、提示词及译文写回见 [TTML 翻译说明](ttml-translation.md)。

上述结果缓存保留 24 小时（积极）或 12 小时（适中）；LunaBeat / AmLyrics 的来源索引独立复用，最多 6 小时，且不计入页面的结果缓存大小。

## 翻译与音译

- Apple 原生源仅在完全没有自带翻译轴、歌曲判定为外文时允许机器/AI 翻译；存在任意自带轴就不补译，也不读取旧机翻缓存。
- AMLL、LunaBeat、AmLyrics、本地 TTML 仅使用自带译文；不因为菜单选择翻译而额外请求机器翻译。无译文会显示不可用状态，保留用户显示偏好。
- 翻译到中文时逐句跳过中文原句与无文字行，无待翻译内容则不请求服务。日/韩上下文、行语言与混合语言识别保持。
- 字体、简体转换和重复副轴隐藏在显示阶段处理，不改原始缓存；外文/日文原词不作中文转换，内容不同的中文转述保留。
- 音译支持自带逐字/逐行数据、离线字典和在线提供方；离线阿语模型使用现有 ONNX 运行时，日语字典和阿语模型仍可独立下载/删除。

## 诊断和验证边界

菜单的高级部分可按需采集 20 秒卡顿诊断并导出 JSON。采集包括 RAF 回调间隔、播放时钟和核心同步耗时，以及浏览器支持的长任务；不包含歌词、网页 URL、账户或翻译凭据。平时不启动采集；暂停、隐藏、切歌或设置变化会终止当前采集。回调 Hz 不等于显示器刷新率或实际呈现 FPS。

生产构建只确认源码能打包，不能替代已登录 Apple Music 的浏览器验证。功能由用户手测；建议更新后覆盖以下场景：

- 切歌、暂停/继续、进度拖动、音量、随机/循环，以及连续开关播放器。
- 同名不同 Apple ID 版本、快速切源、无歌词和原生歌词晚到。
- TTML 导入/替换/移除/刷新恢复，以及设置页删除后的即时同步。
- 翻译配置切换、无译文反馈、字体导入/重置、歌名修正与偏移恢复。
- 菜单/队列互斥、Esc、横竖窗口、浏览器全屏和原生回退。

歌词源：[AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db)、[LunaBeat](https://github.com/2755337087/ttml-hub)、[AmLyrics](https://github.com/Zennmn/am-lyrics)。
